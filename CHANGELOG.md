# Changelog

## 0.15.3
- Every command reaches the API again. The API URL (default `https://storlaunch.forjio.com/api/v1`) is the API root, but paths were joined with `new URL("/discount-codes", root)`, which drops the root's `/api/v1` and landed on the website. Paths now join under the root, whether written `/discount-codes` or `/api/v1/discount-codes`; an API URL set to a bare host gets `/api/v1` added.
- `api-keys revoke` calls `DELETE /account/api-keys/{id}` (the route the API has). Creating or revoking keys needs a signed-in session: with an API key the API answers 403, and the CLI now shows the API's own error message (it read `message` where the API sends `error.message`).

## 0.15.2
- `storlaunch api <area> <action>`: every feature route of the Storlaunch API as a command, flags typed from the API spec (generated by scripts/apigen.sh), using the stored API key like every other command.

## 0.15.1
- Package metadata now points at the public mirror repo (github.com/hachimi-cat/storlaunch-cli).
